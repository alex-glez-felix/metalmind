# Dirección D: lista de notas + nota

Las propuestas de UI de [#164](https://github.com/alex-glez-felix/metalmind/issues/164): abrir `index.html` en un navegador (teclas `1`–`8` cambian de dirección, `t` de tema). Las capturas `direccion-*` y `variante-*` son de ese mockup.

Son referencia de **estructura**, no de píxeles, y su contenido es ficticio. La app las sigue con su propio tema y su fuente; lo que ya está hecho se describe en [05 §2, "Estado"](../../research/05-tags.md) ("Lista de notas").

- **D**: vistas y tags, lista y nota (la elegida).
- **D1**: la lista con dos notas lado a lado (paso 2: splits con la ruta como encabezado).
- **D2**: la lista compacta y el panel de contexto con backlinks y grafo local (paso 3).
- **A**, **A1**, **A2**: la nota sola, que es la lista plegada (`space l`).
